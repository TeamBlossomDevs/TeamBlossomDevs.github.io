Welcome message

Hey Team Blossom members, I’m Shatter — but you can call me Nate! Nice to meet you! We have finally set up the website (after weeks of procrastination and debugging issues), and we’d like to present the first blog post!

What we strive for

What do we plan to do in our development team? We plan to keep 100% transparency between game development and everything inside the studio, to keep everything A-OK. This includes any planned, scrapped, or unreleased concepts, music, and more!

We also want to keep everything open-source — both to keep ourselves accountable and to improve modding capabilities. Please feel free to use the engines if you want, even sell games made with them. All we ask is that you provide credit — that’s it.

Project codenames

We also have several codenames: some for unreleased/planned projects, and some for translation layers!

  • Project-DarkBlossom — Project Dark Blossom (main engine) (formerly DARKTIDE)
  • Project-Parallel — Project-DarkBlossom’s companion game (forked engine) (planned free game)
  • Project-Interactive — An interactive game similar in style to Detroit: Become Human and Dispatch, set in the Project-DarkBlossom universe, with a translation layer to emulate GML code as accurately as possible. (In-house Petal engine, planned game)
  • Project-Delta — DELTARUNE decompilation. We’re aiming to decompile Chapters 1–7 into 100% byte-matching code (or as close as we can get).
  • Petal — Unified language replacing/translating C + ASM + GML. Extension-based engine.
  • blm — Converts GML, C, and ASM code into Petal code files for translation. Custom toolchain required (included with Petal).
  • petal-net — Network extension for any engine using Petal.
  • Petal-3D — Extension required for Petal to render full 3D models.
  • Petal-Text — Required extension for Petal. Allows text, dialogue, and choices to render.
  • petal-bliss — Required extension for Petal. Handles music, sounds, and anything related to the MIDI parser.
  • petal-vid — Required extension for Petal. Enables BVID conversion and playback.
  • petal-btex — Required extension for Petal. Enables textures saved/converted from BTEX files.

That’s just some of the codenames we’ve decided on — more are planned.

More information is available in the dev docs here.

Ending message

As we end this blog post, we’d like to say that we currently want as much help as possible — even something as simple as a texture. Anything is appreciated.

For now, all repositories will remain private until we deem them stable. We just don’t want to drop an unreleased project publicly, y’know?

Also, keep an eye on the repositories if they go public or not. Who knows… maybe it means something’s coming soon. Next blog post in the new year!
